# 요구사항 문서: 대시보드 고도화 (순위·키워드·차트·항목 설명·상세 보기)

## 소개

실제 수집 데이터로 대시보드를 점검한 결과 다음 문제가 확인되었다.

1. GitHub stars(수천)와 Hacker News points(수백)를 같은 숫자로 비교해 Weekly Top 10을 GitHub가 독점했다.
2. 수집일 기준 차트라 첫 수집일에 막대가 하나만 표시되었다.
3. `#cs.ai`, `#agentic ai / generative ai` 처럼 출처 분류 원문이 키워드로 그대로 노출되었다.
4. 각 항목이 무엇을 기준으로 집계되는지 설명이 없었다.
5. 콘텐츠 내용을 보려면 원문 사이트로 이동해야 했다.

## 요구사항

### 요구사항 1: 출처 간 공정한 인기 순위

**사용자 스토리:** 사용자로서, 나는 여러 출처의 인기 콘텐츠가 고르게 섞인 Top 10을 보고 싶다. 그래야 한 출처에 치우치지 않은 트렌드를 볼 수 있다.

#### 인수 기준

1. THE SYSTEM SHALL 인기 지표를 출처 안에서의 순위로 정규화한 점수(`(n - 순위 + 1) / (n + 1)`)로 비교한다.
2. WHEN 같은 출처의 항목이 이미 k개 선택되었으면 THE SYSTEM SHALL 그 출처 항목 점수에 0.7^k 를 곱한다.
3. THE SYSTEM SHALL 같은 출처 안에서는 원래 지표 순서를 유지한다.
4. THE SYSTEM SHALL 지표가 없는 항목을 지표 있는 항목 뒤에 게시일 최신순으로 배치한다.
5. THE SYSTEM SHALL 순위 항목마다 "출처 내 N위/전체" 근거를 표시한다.
6. THE SYSTEM SHALL 같은 입력에 대해 항상 같은 순서를 반환한다.

### 요구사항 2: 게시일 기준 일자별 차트

**사용자 스토리:** 사용자로서, 나는 콘텐츠가 실제로 언제 게시되었는지 분포를 보고 싶다. 그래야 최근 동향을 파악할 수 있다.

#### 인수 기준

1. THE SYSTEM SHALL 최근 7일 차트를 게시일(KST) 기준으로 집계하고, 게시일이 없으면 수집일을 사용한다.
2. THE SYSTEM SHALL 차트 제목에 집계 기준(게시일)을 표시한다.

### 요구사항 3: 키워드 정리

**사용자 스토리:** 사용자로서, 나는 읽기 쉬운 키워드 순위를 보고 싶다. 그래야 트렌드를 바로 이해할 수 있다.

#### 인수 기준

1. THE SYSTEM SHALL arXiv 분류 코드(cs.AI 등)를 읽기 쉬운 이름으로 바꾸고, 목록에 없는 코드는 제외한다.
2. THE SYSTEM SHALL "A / B" 형태의 복합 분류를 개별 키워드로 분리한다.
3. THE SYSTEM SHALL 영문 단어 사이 하이픈·밑줄을 공백으로 정리하고(gpt-4o 처럼 숫자가 섞인 경우 유지) 패키지 메타데이터 태그와 의미 없는 분류를 제외한다.
4. THE SYSTEM SHALL 단수·복수형 키워드를 단수형으로 합쳐 집계한다.
5. THE SYSTEM SHALL 같은 규칙을 수집 저장 시와 화면 표시 시 모두 적용한다 (기존 저장 데이터도 표시 시 정리).
6. WHEN 사용자가 키워드를 누르면 THE SYSTEM SHALL 그 키워드를 포함한 콘텐츠만 Trending에 표시하고, 필터 해제 버튼을 제공한다.

### 요구사항 4: 항목 설명

**사용자 스토리:** 사용자로서, 나는 대시보드 각 항목이 무엇을 어떤 기준으로 보여 주는지 알고 싶다. 그래야 숫자를 올바르게 해석할 수 있다.

#### 인수 기준

1. THE SYSTEM SHALL 대시보드의 모든 지표 카드와 섹션 제목 옆에 설명 버튼(ⓘ)을 제공한다.
2. WHEN 사용자가 설명 버튼을 누르면 THE SYSTEM SHALL 항목의 의미, 집계 기준, 제약(예: LinkedIn 전체 순위 아님)을 표시한다.
3. WHEN 사용자가 Esc 를 누르거나 바깥을 누르면 THE SYSTEM SHALL 설명을 닫는다.
4. THE SYSTEM SHALL 설명 버튼에 "<항목명> 설명" 접근성 이름을 부여한다.

### 요구사항 5: 콘텐츠 상세 보기

**사용자 스토리:** 사용자로서, 나는 원문 사이트로 이동하지 않고 콘텐츠 내용을 확인하고 싶다. 그래야 빠르게 훑어볼 수 있다.

#### 인수 기준

1. WHEN 사용자가 콘텐츠 제목이나 상세 보기 버튼을 누르면 THE SYSTEM SHALL 화면 오른쪽 패널에 상세 내용을 표시한다.
2. THE SYSTEM SHALL 상세 패널에 출처 로고, 제목, 작성자, 게시일·수집일, 유형·언어, 요약(출처 구분 표시), AI 요약 상태, 인기 지표와 의미, 연결된 관심 주제와 관련도, 키워드, 내 메모, 데이터 권한(저장·표시·AI 처리·외부 LLM·보관 기한·출처 정책)을 표시한다.
3. THE SYSTEM SHALL 상세 패널에서 원문 열기(새 탭)와 저장을 제공한다.
4. THE SYSTEM SHALL 본인 콘텐츠만 조회하며(RLS), AI 요약은 AI 처리 권한이 허용된 경우에만 노출한다.
5. WHEN 사용자가 Esc, 닫기 버튼, 배경을 누르면 THE SYSTEM SHALL 패널을 닫는다.
6. THE SYSTEM SHALL 대시보드 목록 카드에도 요약 첫 줄을 표시한다.

### 요구사항 6: 주제별 업데이트 펼치기

**사용자 스토리:** 사용자로서, 나는 주제별 최신 콘텐츠를 대시보드에서 바로 보고 싶다. 그래야 주제 페이지로 이동하지 않아도 된다.

#### 인수 기준

1. WHEN 사용자가 My Topics Update 의 주제 행을 누르면 THE SYSTEM SHALL 최근 7일 최신 콘텐츠 5건을 출처 로고와 함께 펼쳐 보여 준다.
2. WHEN 사용자가 펼친 목록의 제목을 누르면 THE SYSTEM SHALL 상세 보기 패널을 연다.
3. THE SYSTEM SHALL 콘텐츠가 없는 주제는 펼칠 수 없게 한다.
